# 来源契约

授权日历位于 /cal/west/ 和 /cal/east/。使用REPORT，Content-Type: application/xml。calendar-query（urn:ietf:params:xml:ns:caldav）可带time-range，来源保守返回可能相交的完整资源；返回可能多于窗口内课次。calendar-multiget携带多个DAV:href；缺资源以逐项HTTP/1.1 404状态返回。GET资源地址返回text/calendar与ETag。
sync-collection使用DAV命名空间，携带sync-token；空token枚举当前集合。结果是DAV:multistatus，包含href、propstat、getetag、calendar-data和末尾sync-token；已删除资源用response/status 404。当前或紧邻前一阶段token可用，更早或其他日历token返回403 DAV:valid-sync-token。成功空变更与失效token不同。
事件支持DTSTART、DTEND、IANA TZID、每周RRULE COUNT、RDATE、EXDATE、RECURRENCE-ID例外和STATUS:CANCELLED；不使用浮动时间、RANGE=THISANDFUTURE或任意自定义VTIMEZONE。同UID按日历隔离，资源改名会产生旧href删除及新href。RECURRENCE-ID指原始实例，例外DTSTART是实际移到的时刻，取消实例不等于资源删除。
阶段0给重复课表；阶段1给移课和单次取消；阶段2改资源名；阶段3删资源。west使用America/New_York，east使用Asia/Shanghai，两个日历允许同UID。源码包含完整可读取iCalendar原文，UTC偏移由IANA时区数据定义。

演练控制：POST /__control 接收JSON stage及上述控制项，GET /__log显示请求观测；它们供资料源演练与来源测试使用，不属于业务资料获取接口，不得用其直接生成采集结果。每次启动是独立状态。GET /health仅检查服务可用性。
